# 趣 C · 李白 AI 问答大闯关

少儿编程体验课 H5 Demo：由李白 AI 主持出题、学生选择 A/B 答案、AI 判题老师返回结果与解析。

[在线体验](https://quc-li-bai-ai-quiz.chuyunhai5.chatgpt.site)

## 当前能力

- 50 道李白诗词题库
- 每次闯关无重复随机抽取 5 道
- 模拟 AI 出题、判题与加载状态
- 正误反馈、解析、积分和重新闯关
- 浏览器语音朗读题目
- 教研演示代码映射
- 桌面、平板和手机响应式布局

## 本地运行

```bash
npm install
npm run dev
```

## 验证

```bash
npm run test:questions
npm run build
npm run test:sites
```
